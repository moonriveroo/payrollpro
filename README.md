# Payroll Pro

Aplikasi penggajian sederhana berbasis konsol, dibuat dengan Java.

## Fitur
- Login dengan batas 3 kali percobaan
- Tambah karyawan (nama, gaji pokok, jabatan, divisi)
- Lihat data karyawan (nama, jabatan, divisi)
- Hitung gaji per karyawan: gaji pokok + tunjangan 10% - potongan 5% - potongan absen
- Logout

## Cara menjalankan
1. Pastikan JDK sudah terpasang
2. Buka file `PayrollPro.java` di NetBeans (atau IDE Java lainnya)
3. Klik Run
4. Login memakai akun demo yang ada di dalam kode
